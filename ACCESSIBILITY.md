# Accessibility

## Commitment

IntegrationHub is designed to be usable by people with disabilities. **WCAG 2.1 AA** is the target for any web UI: keyboard navigation, screen-reader friendly, and color-contrast compliant.

## Supported Environments

- **Browsers**: Chrome, Firefox, Safari, Edge (latest two versions)
- **Assistive technology**: NVDA, JAWS, VoiceOver, TalkBack
- **OS/device ranges**: Windows, macOS, Linux, iOS, Android

## Known Limitations

- The web admin UI is not yet implemented (Phase 12). No accessibility evaluation has been performed.
- No ARIA labels or keyboard navigation exist today because no UI components are implemented.

## How to Report Barriers

Use the issue template (tag `accessibility`) or email rasimaghayev@gmail.com. Reports are acknowledged within 1 week.
